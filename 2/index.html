Part 1: Polynomial Basis Function

Polynomial Regression

Our goal is to predict median house values based on features describing a town using polynomial regression.

Data Preparation

We used the first 100 data points for training and the remaining points for testing. We normalized the features using the training data's mean $\mu$ and standard deviation $\sigma$ so that the different features were on a similar scale.

$$x' = \frac{x-\mu}{\sigma}$$

Polynomial Basis Functions

Each feature is raised to powers up to the chosen degree $d$. Features are not combined with each other.

$$\phi_{j,k}(\mathbf{x}) = x_j^k, \qquad j = 1,\dots,p, \quad k = 1,\dots,d$$

Here $j$ indexes the feature and $k$ is the power. The model learns one weight per basis function, plus an intercept $w_0$:

$$\hat{y}(\mathbf{x}) = w_0 + \sum_{j=1}^{p}\sum_{k=1}^{d} w_{j,k}\,x_j^k$$

Evaluation

We evaluated each model using the root mean squared (RMS) error on both the training and testing data. The training error measures how well the model fits the training data, while the testing error measures how well it predicts unseen data. A lower RMS error indicates that the predictions are closer to the actual values.

$$\mathrm{RMS} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2}$$

Results

As the polynomial degree increased, the training error decreased because higher-degree models can fit the training data more closely. However, this often causes overfitting and does not generalize well to unseen data. For this dataset, degree 1 has the lowest testing RMS error among the models tested.

Degree 1 Polynomial Regression

The learned bias is 22.3090. The weight for RM (average number of rooms) is 4.1956, while the weight for DIS (distance to employment centers) is 0.0107.

The positive RM weight makes sense because houses with more rooms tend to be worth more. Its relatively large weight also suggests that the number of rooms is one of the more important factors in our model. On the other hand, the DIS weight is very small, meaning distance to employment centers has little effect on our predictions.

Polynomial Regression Regularization

We implemented L2-regularized regression (ridge regression) with a degree 8 polynomial, using only the 2nd feature from the first 100 data points. The model minimizes prediction errors while keeping the weights small:

$$\min_{\mathbf{w}}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2+\lambda\sum_{j=1}^{8}w_j^2$$

To find the best regularization constant $\lambda$, we used 10-fold cross-validation. We split the data into 10 folds, trained on 9 folds, and tested on the remaining fold. We repeated this for each fold and averaged the validation RMS errors for each $\lambda$ value.

Without regularization ($\lambda = 0$), the average validation RMS error was 178.3534. With $\lambda = 1000$, the error dropped to 7.5711, the lowest among all the values we tested. Therefore, we chose $\lambda = 1000$ for the lowest validation error.

Part 2: Gaussian Basis Function

Gaussian Regression

Our goal is to predict median house values from town-level features using Gaussian regression.

Data Preparation

The first 100 data points were used for training and the rest for testing. Features were normalized using the training mean $\mu$ and standard deviation $\sigma$. We tested models with 5, 15, 25, ..., 95 basis functions, with centers chosen at random from the training points.

Gaussian Basis Functions

Each basis function is a bump centered at a chosen point $\boldsymbol{\mu}_j$. Its value is 1 at the center and falls toward 0 as the input moves away.

$$\phi_j(\mathbf{x}) = \exp\left(-\frac{\|\mathbf{x}-\boldsymbol{\mu}_j\|^2}{2s^2}\right), \qquad j = 1,\dots,K$$

Here, $\boldsymbol{\mu}_j$ is the center, $s$ controls the width of the bump, and $K$ is the number of basis functions.

The model learns one weight per basis function, plus an intercept $w_0$, so each center mainly influences predictions for nearby inputs:

$$\hat{y}(\mathbf{x}) = w_0 + \sum_{j=1}^{K} w_j\,\phi_j(\mathbf{x})$$

Fitting and Evaluation

The weights were found by least squares on the training data, without regularization. Models were evaluated by RMS error on the training and testing data.

$$\mathrm{RMS} = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(\hat{y}_i-y_i)^2}$$

Results

Training error generally decreased as basis functions were added, but testing error fluctuated. The lowest testing RMS error was 8.4540, with 45 basis functions. With 95 basis functions, training RMS error fell to 0.2858 while testing RMS error rose to 54.4899, which indicates overfitting.

Gaussian Regression Regularization

We implemented L2-regularized Gaussian regression using the training points as Gaussian basis centers. The model minimizes prediction errors while keeping the weights small:

$$\min_{\mathbf{w}}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2+\lambda\sum_{j=1}^{m}w_j^2$$

To find the best regularization constant $\lambda$, we used 10-fold cross-validation. We split the first 100 data points into 10 folds, trained on 9 folds, and validated on the remaining fold. We repeated this for each fold and averaged the validation RMS errors for each $\lambda$ value.

Without regularization ($\lambda = 0$), the average validation RMS error was 8.0366. With $\lambda = 0.01$, the error dropped to 2.0516, the lowest among all the values we tested. As $\lambda$ increased beyond 0.01, the validation error increased. Therefore, we chose $\lambda = 0.01$ as the best regularization constant.
