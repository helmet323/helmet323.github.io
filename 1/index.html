Part 1: Find shortest distance from a point to a function

Analytical Approach

Given the function f(x) = x2 + 5 and the points (0,0), (-4,0), (-8,0), (2,0), (6,0), we want to find the shortest distance from each point to the function.

The squared distance is

D(x) = (x - x0)2 + (f(x) - y0)2

Taking the derivative and using f(x) = x2 + 5 and f'(x) = 2x, we have

D'(x) = 2(x - x0) + 2(x2 + 5)(2x) = 4x3 + 22x - 2x0

Point (0,0):

Setting D'(x) = 0 gives

0 = 4x3 + 22x

Solving this equation gives x = 0, and therefore f(0) = 5.

Using the closest point (0, 5) and the given point (0, 0), the distance is

d = sqrt((0 - 0)2 + (5 - 0)2) = 5

Point (-4,0):

Setting D'(x) = 0 gives

0 = 4x3 + 22x + 8

Solving this equation gives x ≈ -0.3555, and therefore f(-0.3555) ≈ 5.1264.

Using the closest point (-0.3555, 5.1264) and the given point (-4, 0), the distance is

d = sqrt((-0.3555 + 4)2 + (5.1264 - 0)2) ≈ 6.2898

We can repeat this process for the other points, and the results are summarized in the table below.

Newton-Raphson Method

Given f(x) = x2 + 5 and f'(x) = 2x, we have

D'(x) = 4x3 + 22x - 2x0    D''(x) = 12x2 + 22

We update x using the Newton-Raphson formula:

xn+1 = xn - (D'(xn) / D''(xn))

We start with the initial guess x0 = 0.0 and ends when next_x - x < tolerance = 1e-7:

We explore the Newton-Raphson method on non-polynomial functions, such as the exponential function.

Given f(x) = 2x + 2 and f'(x) = 2x * ln(2) and point (6, 0), we have
