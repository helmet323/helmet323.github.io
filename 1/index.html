Part 1: Find shortest distance from a point to a function

Analytical Approach

Given the function \(f(x) = x^2 + 5\) and the points \((0,0), (-4,0), (-8,0), (2,0), (6,0)\), we want to find the shortest distance from each point to the function.

We measure the distance using the Euclidean distance formula:

\[ d = \sqrt{(x - x_0)^2 + (f(x) - y_0)^2} \]

To simplify the calculations, we can minimize the squared distance instead of the actual distance. Both reach their minimum at the same point, so we can avoid working with the square root.

\[ D(x) = (x - x_0)^2 + (f(x) - y_0)^2 \]

To find the closest point, we take the derivative of the squared distance and set it to zero. This allows us to find where the distance is minimized.

Using \(f(x) = x^2 + 5\) and \(f'(x) = 2x\), we get:

\[ \begin{aligned} D'(x) &= 2(x-x_0) + 2(x^2+5 - y_0)(2x) \\ &= 4x^3 + 22x - 4xy_0 - 2x_0\end{aligned} \]

By hand: Point \((0,0)\)

Setting \(D'(x) = 0\) and substituting \((0, 0)\) gives:

\[ 0 = 4x^3 + 22x \]

Solving this equation gives \(x = 0\), and therefore \(f(0) = 5\).

Using the closest point \((0,5)\) and the given point \((0,0)\), the distance is:

\[ d = \sqrt{(0-0)^2 + (5-0)^2} = 5 \]

By hand: Point \((-4,0)\)

Setting \(D'(x) = 0\) and substituting \((-4, 0)\) gives:

\[ 0 = 4x^3 + 22x + 8 \]

Solving this equation gives \(x \approx -0.3555\), and therefore \(f(-0.3555) \approx 5.1264\).

Using the closest point \((-0.3555, 5.1264)\) and the given point \((-4,0)\), the distance is:

\[ d = \sqrt{(-0.3555+4)^2 + (5.1264-0)^2} \approx 6.2898 \]

Newton-Raphson Method

We use the Newton-Raphson method when we can easily calculate the first and second derivatives of \(f(x)\). We also need an initial guess for \(x\) and a tolerance level to determine when to stop iterating.

Again, we use the squared distance function:

\[ D(x) = (x - x_0)^2 + (f(x) - y_0)^2 \]

Given \(f(x) = x^2 + 5\), \(f'(x) = 2x\), and \(f''(x) = 2\), the derivatives of \(D(x)\) are:

\[ \begin{aligned} D'(x) &= 4x^3 + 22x - 4xy_0 - 2x_0 \\ D''(x) &= 12x^2 + 22 - 4y_0 \end{aligned} \]

We update \(x\) using the Newton-Raphson formula:

\[ x_{n+1} = x_n - \frac{D'(x_n)}{D''(x_n)} \]

We start with the initial guess \(x_0 = 0.0\) and continue iterating until the change between two consecutive estimates is smaller than the tolerance \(1 \times 10^{-7}\):

\[ |x_{n+1} - x_n| < 10^{-7} \]

The shortest distance between the given point \((0, 0)\) and the closest point \((0, 5)\) is:

\[ d = \sqrt{(0-0)^2 + (5-0)^2} = 5 \]

Golden Section Search

We use the Golden Section Search method when we don't know the derivatives of \(f(x)\) or when the derivatives are difficult to calculate. For this method, we only need an estimate of the interval that contains the minimum and a tolerance level to determine when to stop iterating.

Given the function \(f(x) = x^2 + 5\), we want to find the minimum of the squared distance function \(D(x)\).

We start with an initial interval \([a,b]\). At each iteration, we calculate two points inside the interval using the golden ratio. We have:

\[ \phi = \frac{1+\sqrt{5}}{2} \]

and

\[ \text{resphi} = 2-\phi. \]

Thus, the two points are

\[ x_1 = a+\text{resphi}(b-a) \]

\[ x_2 = b-\text{resphi}(b-a). \]

Then, if the squared distances \(D(x_1) < D(x_2)\), we move the right endpoint to \(x_2\). Otherwise, we move the left endpoint to \(x_1\). We continue this process until the length of the interval is smaller than the tolerance \(1\times10^{-7}\). Finally, we use the midpoint of the remaining interval as our estimate for the closest point on the curve.

Part 2: Fitting to an equation

Analytical method

Fit to line

Given the points \((0, 0.5), (2, 3.5), (1, 1.5), (3, 7.5)\), we want to fit them to a line \(y = c_0 + c_1x\). For each point \((x_i, y_i)\), we have the squared error \([y_i-(c_0+c_1x_i)]^2\). Thus, we want to minimize the following error:

\(E(c_0, c_1)=\sum_{i=1}^{n} (y_i-c_0-c_1x_i)^2\)

Subbing in the points, we have

\(E(c_0,c_1) = (0.5-c_0)^2 + (3.5-c_0-2c_1)^2 + (1.5-c_0-c_1)^2 + (7.5-c_0-3c_1)^2\)

Taking the partial derivatives and setting them equal to zero, we have

\( \begin{aligned} \frac{\partial E}{\partial c_0} &= -2(0.5-c_0)\\ &-2(3.5-c_0-2c_1)\\ &-2(1.5-c_0-c_1)\\ &-2(7.5-c_0-3c_1) = 0\end{aligned} \)

\( \begin{aligned} \frac{\partial E}{\partial c_1} &=-4(3.5-c_0-2c_1)\\ &-2(1.5-c_0-c_1)\\ &-6(7.5-c_0-3c_1) = 0 \end{aligned} \)

Simplifying, we get the following system of linear equations:

\( \begin{aligned} 4c_0+6c_1 &= 13\\ 6c_0+14c_1 &= 31 \end{aligned} \)

We can write this system in matrix form as

\( \begin{bmatrix} 4 & 6\\ 6 & 14 \end{bmatrix} \begin{bmatrix} c_0\\ c_1 \end{bmatrix} = \begin{bmatrix} 13\\ 31 \end{bmatrix} \)

Solving this system gives

\( c_0=-0.2,\qquad c_1=2.3 \)

Therefore, we have the line \(y=-0.2+2.3x\)

Fit to quadratic

Given the points \((0, 0.5), (2, 3.5), (1, 1.5), (3, 7.5)\), we want to fit them to a quadratic \(y = c_0 + c_1x + c_2x^2\). For each point \((x_i,y_i)\), we have the squared error \([y_i - (c_0 + c_1x_i + c_2x_i^2)]^2\). Thus, we minimize the following error:

\( E(c_0,c_1,c_2) = \sum_{i=1}^{n}(y_i-c_0-c_1x_i-c_2x_i^2)^2 \)

Subbing in the points, we have

\( \begin{aligned} E(c_0,c_1,c_2) = &(0.5-c_0)^2 \\ &+(3.5-c_0-2c_1-4c_2)^2 \\ &+(1.5-c_0-c_1-c_2)^2 \\ &+(7.5-c_0-3c_1-9c_2)^2 \end{aligned}\)

Taking the partial derivatives and setting them equal to zero, we have

\( \begin{aligned} \frac{\partial E}{\partial c_0} = &-2(0.5-c_0)\\ &-2(3.5-c_0-2c_1-4c_2)\\ &-2(1.5-c_0-c_1-c_2)\\ &-2(7.5-c_0-3c_1-9c_2)=0 \end{aligned} \)

\( \begin{aligned} \frac{\partial E}{\partial c_1} = &-4(3.5-c_0-2c_1-4c_2)\\ &-2(1.5-c_0-c_1-c_2)\\ &-6(7.5-c_0-3c_1-9c_2)=0 \end{aligned} \)

\( \begin{aligned} \frac{\partial E}{\partial c_2} = &-8(3.5-c_0-2c_1-4c_2)\\ &-2(1.5-c_0-c_1-c_2)\\ &-18(7.5-c_0-3c_1-9c_2)=0 \end{aligned} \)

Simplifying, we get the following system of linear equations:

\( \begin{aligned} 4c_0+6c_1+14c_2 &= 13\\ 6c_0+14c_1+36c_2 &= 31\\ 14c_0+36c_1+98c_2 &= 83 \end{aligned} \)

We can write this system in matrix form as

\( \begin{bmatrix} 4 & 6 & 14\\ 6 & 14 & 36\\ 14 & 36 & 98 \end{bmatrix} \begin{bmatrix} c_0\\ c_1\\ c_2 \end{bmatrix} = \begin{bmatrix} 13\\ 31\\ 83 \end{bmatrix} \)

Solving this system gives

\( c_0=0.55,\qquad c_1=0.05,\qquad c_2=0.75 \)

Therefore, we have the quadratic \( y=0.55+0.05x+0.75x^2 \)

Fit to line

Given the points $(0, 0.5), (1, 1.5), (2, 3.5), (3, 7.5)$, we want to fit them to a line $y = c_0 + c_1 x$ using the multidimensional Newton-Raphson method to minimize the squared error $E(c_0, c_1) = \sum_{i=1}^{n}(y_i - c_0 - c_1 x_i)^2$.

Substituting the points into the squared error gives:

$E(c_0, c_1) = (0.5 - c_0)^2 + (1.5 - c_0 - c_1)^2 + (3.5 - c_0 - 2c_1)^2 + (7.5 - c_0 - 3c_1)^2$

The first derivative $\nabla E$:

$\dfrac{\partial E}{\partial c_0} = 8c_0 + 12c_1 - 26$

$\dfrac{\partial E}{\partial c_1} = 12c_0 + 28c_1 - 62$

The second derivative gives:

$\dfrac{\partial^2 E}{\partial c_0^2} = 8, \quad$ $\dfrac{\partial^2 E}{\partial c_0\,\partial c_1} = 12, \quad$ $\dfrac{\partial^2 E}{\partial c_1\,\partial c_0} = 12, \quad$ $\dfrac{\partial^2 E}{\partial c_1^2} = 28$

Thus the Hessian $\mathbf{J} = \begin{bmatrix} 8 & 12 \\ 12 & 28 \end{bmatrix}$ and its inverse is $\mathbf{J}^{-1} = \begin{bmatrix} 0.35 & -0.15 \\ -0.15 & 0.1 \end{bmatrix}$
